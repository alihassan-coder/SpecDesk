# Glossary

| Term | Meaning |
|---|---|
| **Idea** | The founder's free-text description of the app they want. |
| **Chat** | One planning conversation about one idea. Owned by one user. |
| **Round** | A batch of numbered questions the Interviewer asks at once. Each has a recommended answer and option chips. |
| **Frontier** | The questions that can be asked now because everything they depend on is answered. |
| **Agent** | One specialised step of the pipeline (Interviewer, Analyst, Product, UX, Architect, Estimator, Critic, Researcher). |
| **Note** | A short, human-readable progress line from an agent. |
| **Reasoning** | An agent's longer explanation of why it decided something (shown collapsed). |
| **Plan** | The structured result of a chat: features, screens, stack, timeline, price, risks… |
| **Version** | An immutable snapshot of a plan. Scope changes create a new version. |
| **Diff** | What changed between two versions, including price and time deltas. |
| **Scope** | Which features are included. Changing scope recomputes price and timeline. |
| **Readiness score** | 0–100 rating of how ready the idea is to build, with reasons. |
| **File / Artifact** | A generated download (PDF, spec.md, backlog.csv, build-prompt.md, flow.mmd, ZIP), opened in the artifact panel. |
| **Lead** | A founder the agency could work with; created on sign-up, updated on booking. |
| **Guest** | A visitor exploring the demo without signing in. |
