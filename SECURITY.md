# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through [GitHub Security Advisories](https://github.com/alihassan-coder/SpecDesk/security/advisories/new).
Include steps to reproduce, the impact, and any suggested fix.

You'll get a reply within 3 working days. We'll keep you updated until it's fixed and credit you
in the release notes if you'd like.

## Scope
Especially interesting: access to another user's chats or plans, auth bypass, leaking provider API keys,
prompt injection that exposes other users' data, and webhook signature bypass.
